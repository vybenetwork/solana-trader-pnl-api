VybeTrader PnL

Wallet profit and loss, plus a PnL chart

Enter a wallet for its profit and loss, or a mint for the traders with the most realized PnL on that token. The wallet summary includes realized and unrealized results, plus volume, for the window you pick.

The chart buckets PnL at daily, weekly, or monthly. Table windows are 1d, 7d, and 30d. Related top traders load with the wallet, and a mint lookup ranks who made the most on that token. Chart points follow the resolution you select, and those three buckets are the only ones. A free API key on Vybe is enough to start. Paid plans raise the rate limit.

Generate a free API key to get started

Endpoints Used:

  • Trader PnL API GET /v4/wallets/{ownerAddress}/pnl
  • Top Traders API GET /v4/wallets/top-traders
  • Top PnL Traders API GET /v4/tokens/{mintAddress}/top-pnl-traders
  • Historical Trades API GET /v4/trades
  • Token Details API GET /v4/tokens/{mintAddress}
  • Labeled Programs GET /v4/programs/labeled-program-accounts

  • Wallet summary

    Realized and unrealized PnL for the wallet and window you pick.

  • PnL chart

    A timeseries of that wallet's PnL at daily, weekly, or monthly.

  • Token leaderboard

    Traders ranked by realized PnL on the mint you enter.

  • Related wallets

    Other top traders returned alongside the wallet lookup.

Also answered here

What does a wallet lookup show?

Profit and loss for the wallet, a PnL chart, and related top traders.

How do I get a Vybe API key?

Generate a free API key on Vybe. A free key starts your first calls. Paid plans raise the rate limit.

Which chart resolutions are available?

Daily, weekly, or monthly for the chart. Tables use 1d, 7d, and 30d.
